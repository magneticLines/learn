搭配与语域：为什么"语法对但没人这么说"

阶段 4 开始，问题从"能不能"变成"好不好"。这一节解决那个最让人困惑的反馈 —— 每个词都查过、语法完全正确，母语者却说"能懂，但我们不这么说"。原因是两个你从没系统学过的维度：搭配和语域。

PART 1 学习资料 读完再动手 · 约 25 分钟

搭配：约定，不是规则

W15 提过这一点，这里展开。搭配（collocation）是词与词之间的习惯性同现，它不能从词义推导出来。

类型对错（语法没问题）
动词 + 名词make a decisiondo a decision
动词 + 名词raise a concernrise a concern / put a concern
动词 + 名词run into an issuemeet an issue
形容词 + 名词a strong argumenta powerful argument（弱一些，能用但不地道）
副词 + 形容词highly unlikelystrongly unlikely
名词 + 名词a security breacha security break
动词 + 副词fail silentlyfail quietly（技术语境里不地道）
为什么这些不能推导：因为它们是历史沉淀，不是逻辑结果。

make 和 do 的语义边界没有清晰规则 —— make a decision、do research、make progress、do a favor。母语者不是靠推导，是靠几万小时的接触记住了整块。

所以搭配只能通过两个途径获得：大量接触（慢）、或者主动查验并入库（快）。后者是你的优势 —— 你有工具，也有工程化的习惯。

怎么验证一个搭配是否地道（具体方法）

  • Ludwig（ludwig.guru）　输入你的说法，它从真实语料里给出例句和频率。最直接的工具
  • Ozdic（ozdic.com）　搭配词典。查一个名词，列出它常配的动词、形容词
  • Google 精确匹配　把短语加引号搜索，看结果数量和来源质量。注意排除中国网站的结果（可能都是同样的错误）
  • Youglish　听真人在真实语境里怎么说，顺便校准发音
  • AI + 验证　AI 给的表达要用上面的工具验一遍。AI 会产生"语法完美但无人使用"的表达（W2 的第四个失效模式）

语域：底层规律是词源

这一节最有用的一个发现：英语词汇的正式程度，大体由词源决定。

日耳曼词源（本土）拉丁 / 法语词源（外来）
特征短、常见、口语长、正式、书面
例子get / ask / buy / start / end / help / show / needobtain / request / purchase / commence / terminate / assist / demonstrate / require
动词短语find out / put off / look into / set upascertain / postpone / investigate / establish
用在口语、Slack、日常邮件正式文档、合同、学术
这条规律给了你一个可推导的旋钮，而不是死记硬背。

想让表达更口语 → 换成短的日耳曼词，尤其是动词短语（look into 而不是 investigate）。
想让表达更正式 → 换成长的拉丁词。

而且这解释了你的一个具体问题：你的英语从阅读来，读的是文档和技术书（正式文体），所以你的主动词汇偏拉丁词源 —— 说出来自然偏书面。知道这条规律，你就有了明确的调整方向：多用动词短语。

注意"很随意"和"口语"两列大量使用动词短语（push back / put off / kick off / wrap up / hit a snag）。动词短语是英语口语的主力，也是中文母语者用得最少的一类 —— 因为它们在词典里不好查、在正式文档里不出现。

三条实用判断

  • 不确定语域时选"中性"。它在任何场合都不出错，只是不出彩
  • 口语里优先动词短语。这是让表达听起来自然的最快手段
  • 混用语域是明显的信号。Hey Dave, I would like to ascertain whether the deployment has commenced —— 招呼是随意的，内容是合同语言，这个落差非常刺耳

常见陷阱

  • 把搭配当语法问题去理解。想找规则解释为什么是 make a decision —— 没有规则，只有约定。接受这一点能省很多时间。
  • 相信 AI 给的表达不验证。AI 会产生语法完美但真实语料里罕见的搭配。入库前用 Ludwig 验一遍。
  • 用 Google 结果数量当唯一标准。要看来源 —— 如果搜出来全是中国网站，那可能是共同的错误。
  • 过度使用正式词汇。本节最针对你的一条：阅读来的英语天然偏拉丁词源。刻意多用动词短语来平衡。
  • 混用语域。随意的招呼 + 正式的内容，落差刺耳。
  • 为了"高级"而用长词。母语者的口语用的是短词。用 utilize 代替 use 不会显得高级，只会显得不自然（这在英语写作圈是个著名的槽点）。
  • 只学不入库。搭配是海量的，学过就忘。必须进 chunks.md 并标注语域。
