# 学习项目补充规划

> 本文件用于记录当前知识库中尚未覆盖、或覆盖不足的知识点，以及后续补齐的优先级建议。
> 分析时间：2026-07-06

## 一、明显缺口 · 建议优先补齐

### 1. TypeScript
- **现状**：前端路径缺失 TS，但现代 React/Node/工程化几乎都离不开。
- **建议模块**：
  - TS 类型基础与类型推断
  - 泛型
  - 实用类型（`Partial`、`Pick`、`Omit` 等）
  - 配置与工程化（`tsconfig`、`dts`、类型声明文件）

### 2. HTTP 深入（协议层）
- **现状**：前端已有 JS/HTML，安全专题已有，但 HTTP 协议细节缺独立专题。
- **建议模块**：
  - HTTP 缓存策略（`Cache-Control`、ETag、`Last-Modified`）
  - HTTP/2 与 HTTP/3 细节
  - WebSocket
  - CORS、同源策略
  - 请求握手与连接管理

### 3. 前端构建与工程化
- **现状**：React 篇提到了 Vite，但没有打包/构建原理专题。
- **建议模块**：
  - 模块化与打包原理（CommonJS / ESM）
  - Tree Shaking 与副作用标记
  - Code Splitting 与动态导入
  - Vite / Webpack / Rollup 对比与原理
  - 模块联邦（Module Federation）

### 4. Node.js 运行时
- **现状**：纯浏览器 JS → React，缺 Node runtime 专题。
- **建议模块**：
  - Node 事件循环与浏览器事件循环差异
  - Stream（可读流、可写流、Transform）
  - `fs` / `path` / `http` 模块实战
  - Express / Fastify 框架对比
  - NestJS / Egg.js 企业级框架

### 5. Java 测试体系
- **现状**：有 Python 测试实战，但缺 Java 生态测试专题。
- **建议模块**：
  - JUnit 5 深入（生命周期、参数化、扩展模型）
  - Spring Boot 测试（`@SpringBootTest`、切片测试）
  - MockMvc / TestRestTemplate
  - Testcontainers
  - Mockito 与 `@Mock` / `@InjectMocks` 详解

## 二、现有轨道的深化建议

### 数据库（09）
- 当前偏 MySQL / 关系型
- 可补齐：
  - PostgreSQL 特性与适用场景
  - HikariCP 连接池原理
  - 分库分表中间件（ShardingSphere）
  - ORM 选型细节（JPA vs MyBatis）

### 消息队列（13）
- 当前已有 RocketMQ
- 可补齐：
  - Kafka 生产环境运维
  - RabbitMQ 经典模式（Work/Topic/Pub-Sub）
  - 分布式事务（Seata、可靠消息最终一致性）

### 分布式与微服务（14）
- 当前已有基础微服务
- 可补齐：
  - 分布式事务（TCC / Saga / Seata）
  - 分布式 ID（雪花算法、Leaf、Redis 自增）
  - 分布式锁实现（Redisson、Curator）

### 可观测性（17）
- 当前已有 APM / 链路追踪
- 可补齐：
  - OpenTelemetry 标准与生态
  - Grafana 大盘设计
  - SLI / SLO / 告警策略实战
