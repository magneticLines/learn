CPU 1214C · 博图 V16 · WinCC V7.5 · NetToPLCsim

1214C 本机联调：博图程序连 WinCC 画面

没有真实 PLC，博图 V16 写的 1214C 程序、WinCC V7.5 做的画面都在同一台电脑上。按这一页从上到下做，就能让 WinCC 画面读写仿真 PLC 里的数据。

这套环境里每个软件的角色

博图 V16写程序、下载编写 1214C 的 PLC 程序，编译后下载到仿真 PLC。
S7-PLCSIM V16假装成一台 1214C西门子官方的 PLC 仿真器，在电脑里运行你的 PLC 程序。和博图是两个产品，要单独安装。
NetToPLCsim翻译 / 转发免费第三方工具，在本机网卡上开 102 端口，把 WinCC 的请求转给 PLCSIM。
WinCC V7.5上位机画面按 IP 去连 NetToPLCsim，读写 PLC 变量并显示在画面上。
原理

为什么中间要多一个 NetToPLCsim

PLCSIM 不对外开放

博图自带的 PLCSIM 只和博图内部通信，没有网络接口，WinCC 按 IP 找不到它。能对外开放网络的 PLCSIM Advanced 又只支持 S7-1500，不支持 1214C。NetToPLCsim 正好填这个空：它在本机网卡上监听 S7 通信端口 TCP 102，把 WinCC 发来的请求转给 PLCSIM，WinCC 就以为自己连上了一台真实 PLC。

代价：只能用绝对地址

经过 NetToPLCsim 转发时，只支持 S7 的 PUT/GET 读写，也就是按 DB1.DBX0.0 这种“块号 + 字节偏移”访问。WinCC 的“从 AS 读取符号”用不了，变量要按 DB 的偏移量手工建。为此 PLC 要勾 PUT/GET，DB 块要取消“优化的块访问”。

准备阶段

软件准备：先确认四个软件都装好

这四个软件是分开安装的。装了博图不代表就有 PLCSIM，NetToPLCsim 更不在任何西门子安装包里。开始联调前，先对照下表把缺的补齐。

软件作用从哪来费用
博图 STEP 7 V16写 PLC 程序、下载西门子官网，或学校 / 公司提供的安装包收费，有试用授权
S7-PLCSIM V16仿真 PLC，运行程序单独下载，西门子官网收费，有试用授权
WinCC V7.5做上位机画面单独下载，西门子官网收费，有试用授权
NetToPLCsim把 PLCSIM 开放到网络单独下载，SourceForge免费开源
PLCSIM 是什么

S7-PLCSIM 是西门子官方的 PLC 仿真软件，在电脑里“假装”成一台真实 PLC。博图把程序下载给它，它就像真 PLC 一样执行，你可以在博图里在线监视、修改变量。它没有物理输入输出，也不对外开放网络，所以本方案要靠 NetToPLCsim 把它接到网络上。

容易混淆的版本搭配软件支持的 PLC网络接口本方案是否需要
S7-PLCSIM V5.x经典 STEP 7 V5.xS7-300 / 400无不需要
S7-PLCSIM V16博图 V16S7-1200 / 1500无需要
S7-PLCSIM Advanced V3.0博图 V16仅 S7-1500有仅备选方案
版本必须一致：PLCSIM 的版本号要和博图完全相同。博图 V16 只能配 PLCSIM V16，装成 V15 或 V17 都用不了。

  1. 检查是否已经装好

    很多博图安装包里自带 PLCSIM 的安装文件夹，先确认一下，满足任一条就说明已经装好：

    • 开始菜单的 Siemens Automation 文件夹里有 S7-PLCSIM V16、WinCC。
    • 博图里选中 PLC，工具栏的 开始仿真 按钮可以点。
    • 控制面板›程序和功能 里能看到 SIMATIC S7-PLCSIM V16。

  2. 下载西门子软件

    • 如果博图是学校或公司给的，先找他们要完整安装包，PLCSIM 和 WinCC 通常都在里面，比自己下载省事。
    • 自己下载的话，打开西门子工业支持网站 support.industry.siemens.com（SiePortal），注册账号并登录。注册免费，但审核可能要几小时到一两天。
    • 搜索 S7-PLCSIM V16 Trial、WinCC V7.5 Trial，下载试用版。
    • 下载下来通常是多个压缩分卷，放到同一个文件夹，只解压第一个，后面的分卷会自动合并。
    官网页面经常改版，具体入口以搜索结果为准。

  3. 下载 NetToPLCsim

    在 SourceForge 搜索 NetToPLCsim，从官方项目页下载最新版。它是绿色软件，解压就能用，不需要安装。

    只从官方项目页下载：不要用网盘或软件站的转载包，可能被捆绑了其他程序。它会监听端口、停系统服务，杀毒软件可能误报，确认来源后加入信任即可。

  4. 按顺序安装

    建议顺序：WinCC V7.5 → 博图 STEP 7 V16 → S7-PLCSIM V16 → 解压 NetToPLCsim。

    • PLCSIM 要挂到博图里才能用，必须先装博图再装 PLCSIM，反了博图可能识别不到。
    • WinCC 和博图会共用一部分西门子底层组件。装之前可以用西门子官网的 Compatibility Tool 确认这两个版本能装在同一台电脑上。
    • 安装前关闭杀毒软件，安装路径不要有中文。
    • 提示重启就重启。西门子软件经常要重启好几次，跳过重启是安装报错的常见原因。

  5. 确认授权

    打开开始菜单里的 Automation License Manager，确认博图、PLCSIM、WinCC 都有授权。试用版第一次运行时会提示激活试用授权，一般能用 21 天。没有授权时 PLCSIM 无法启动，WinCC 会以演示模式运行，一段时间后自动退出。

  6. 确认 1214C 的固件版本

    PLCSIM 只能仿真固件 V4.0 及以上的 S7-1200。在博图设备组态里选中 CPU，查看 属性›常规›目录信息 中的固件版本。版本太老的话，右键 CPU → 更改设备，换成同型号的 V4.x 固件。

第一阶段

博图 V16：准备 PLC 程序并启动仿真

  1. 打开仿真支持

    项目树里右键 项目名 → 属性›保护，勾选 块编译时支持仿真。不勾的话，下载到 PLCSIM 时会提示不支持。

  2. 放开 PLC 的访问权限

    双击 PLC_1 [CPU 1214C] → 属性›常规›防护与安全：

    • 访问级别：选“完全访问权限（无任何保护）”。
    • 连接机制：勾选 允许来自远程对象的 PUT/GET 通信访问。WinCC 读写数据靠的就是 PUT/GET，不勾的话连接正常但读不到值。

  3. 设定 PLC 的 IP

    属性›常规›PROFINET 接口›以太网地址，IP 设为 192.168.0.1，子网掩码 255.255.255.0。NetToPLCsim 会按这个 IP 找到仿真 PLC。

  4. 给 WinCC 用的 DB 块取消“优化的块访问”

    • 建议专门建一个数据块（比如 DB1 HMI_Data），把要在画面上显示和操作的变量都放进去。
    • 右键 DB → 属性 → 属性页，取消勾选“优化的块访问”，确定后编译。
    • 打开 DB，会多出一列 偏移量。WinCC 里的地址就按这一列填，后面会用到。
    为什么必须取消

    “优化的块访问”打开后，PLC 会自行安排变量的存储位置，变量没有固定的字节偏移量，DB1.DBX0.0 这样的地址也就不存在。取消后变量按声明顺序依次排列，每个变量都有确定的偏移量。

    示例：DB1 里依次声明 Start : Bool、Stop : Bool、Speed : Int、Temp : Real，偏移量通常是 0.0、0.1、2.0、4.0。Int 和 Real 会对齐到偶数字节，所以 Speed 从 2.0 开始而不是 1.0，以博图里显示的偏移量为准。

  5. 启动 PLCSIM 并下载

    • 选中 PLC → 工具栏 开始仿真，PLCSIM 窗口弹出。
    • 博图随即弹出下载对话框，接口选 PLCSIM 那一项，搜索到 192.168.0.1 后下载。硬件配置和程序一起下，IP 和 PUT/GET 设置都在硬件配置里。
    • 下载完成后把 PLCSIM 切到 RUN，指示灯变绿。
第二阶段

添加一块环回网卡，给 NetToPLCsim 用

为什么不用真实网卡

NetToPLCsim 需要一个本机 IP 来监听。用环回网卡（一块只存在于系统里的虚拟网卡）不受网线是否插着、公司网络 IP 是多少的影响，联调最稳定。

  1. 安装环回网卡

    Win + R 输入 hdwwiz 回车 → 下一步 → 安装我手动从列表选择的硬件 → 网络适配器 → 厂商选 Microsoft，型号选 Microsoft KM-TEST 环回适配器 → 完成。

  2. 给它设静态 IP

    控制面板 → 网络连接，找到新出现的环回网卡 → 属性 → Internet 协议版本 4：IP 192.168.0.10，掩码 255.255.255.0，网关留空。

    注意网段冲突：如果你的真实网卡也在 192.168.0.x 网段，就把这一整套换成 192.168.100.x：环回网卡 192.168.100.10，博图里 PLC 改为 192.168.100.1 并重新下载。
第三阶段

配置 NetToPLCsim

  1. 下载并以管理员身份运行

    用准备阶段下载的 NetToPLCsim 最新版（它对 PLCSIM V16 的支持取决于自身版本）。解压后右键 NetToPLCsim.exe → 以管理员身份运行。

  2. 让出 102 端口

    启动时如果提示 102 端口被占用，并询问是否停止 S7DOS Help Service（有的版本叫 IEPG Help Service），选 是。这个西门子服务默认占着本机的 102 端口，不停掉 NetToPLCsim 就无法监听。

    停掉这个服务只影响本次开机。电脑重启后它会自动恢复，下次联调时 NetToPLCsim 会再问一次。

  3. 添加站点

    点 Add，填写：

    字段填什么含义
    NamePLC_1214C随便起
    Network IP Address192.168.0.10点旁边的按钮选环回网卡。WinCC 要连的就是这个地址
    Plcsim IP Address192.168.0.1博图里 PLC 的 IP，可以点按钮从正在运行的 PLCSIM 中选
    Rack / Slot0 / 1S7-1200 固定是机架 0、插槽 1

  4. 启动转发

    点 Start Server，站点状态显示 running 即可。cmd 里 ping 192.168.0.10 应该能通。

第四阶段

WinCC V7.5：建连接、建变量、做画面

  1. 把访问点指向环回网卡

    控制面板 → 设置 PG/PC 接口：应用程序访问点下拉选 CP-TCPIP（没有的话选“添加/删除”新建一个），分配给 Microsoft KM-TEST 环回适配器.TCPIP.1，确定。

  2. 添加驱动

    WinCC 项目管理器 → 变量管理 → 右键 添加新的驱动程序 → 选 SIMATIC S7 Protocol Suite。

    这里用经典的 S7 Protocol Suite，不用 “S7-1200, S7-1500 Channel”。后者主打符号访问，而本方案只能走 PUT/GET 绝对地址，经典驱动对此最稳。

  3. 确认通道单元的逻辑设备名称

    展开驱动 → 右键 TCP/IP 通道单元 → 系统参数 → 单元页，逻辑设备名称应为 CP-TCPIP，也就是上一步指向环回网卡的那个访问点。

  4. 新建连接

    右键 TCP/IP → 新建连接，命名 PLC_1214C → 右键 连接参数：

    • IP 地址：192.168.0.10，填 NetToPLCsim 监听的地址，不是 PLC 的 192.168.0.1。
    • 机架号 0，插槽号 1。

  5. 按偏移量建变量

    选中连接 → 在右侧变量表里新建变量，地址按博图 DB 的偏移量填写：

    博图变量偏移量WinCC 数据类型WinCC 地址
    Start : Bool0.0二进制变量DB1.DBX0.0
    Stop : Bool0.1二进制变量DB1.DBX0.1
    Speed : Int2.0有符号 16 位数DB1.DBW2
    Temp : Real4.0浮点数 32 位 IEEE 754DB1.DBD4
    地址规则：X 是位（字节.位），B 是字节，W 是 2 字节的字，D 是 4 字节的双字。M 区、I/Q 区写成 M10.0、MW20、I0.0、Q0.0，不用改 DB 设置也能访问。

  6. 画面绑定变量

    • 打开 图形编辑器，新建画面，放一个 I/O 域，组态对话框里变量选 Speed，更新周期 500 ms。
    • 放一个 按钮：属性 → 事件 → 鼠标 → 按左键选“直接连接”，常数 1 写入变量 Start；释放左键写 0，就是一个点动按钮。

  7. 设置启动画面并激活

    项目管理器 → 计算机 → 属性 → 启动页勾选“图形运行系统”，图形运行系统页选起始画面。点工具栏 ▶ 激活。

    验证：在博图里监视 DB1，改 Speed 的值，WinCC 画面跟着变；在 WinCC 里按按钮，博图里 Start 跟着变。双向都通，就说明联调成功。

日常使用

每次联调的启动顺序

  1. 博图 V16：开始仿真 → 下载 → RUN

    PLC 程序有修改时重新下载；改了 DB 结构的话，WinCC 里对应变量的地址也要按新的偏移量更新。

  2. NetToPLCsim：管理员运行 → Start Server

    必须在 PLCSIM 已经运行之后再启动，否则它找不到仿真 PLC。

  3. WinCC V7.5：激活运行

    关闭时反过来：先退出 WinCC 运行，再停 NetToPLCsim，最后关 PLCSIM。

联调前

检查清单

  • 博图 V16、S7-PLCSIM V16、WinCC V7.5 已安装且有授权，NetToPLCsim 已解压
  • 1214C 固件版本为 V4.0 及以上
  • 项目已勾“块编译时支持仿真”
  • PLC 访问级别为完全访问，已勾 PUT/GET
  • 给 WinCC 用的 DB 已取消“优化的块访问”，并记下了每个变量的偏移量
  • 硬件配置和程序都已下载到 PLCSIM，PLCSIM 处于 RUN
  • 环回网卡 IP 为 192.168.0.10，与 PLC 同网段但不相同
  • NetToPLCsim 以管理员运行，站点为 192.168.0.10 → 192.168.0.1，机架 0 插槽 1，已 Start Server
  • 设置 PG/PC 接口中 CP-TCPIP 指向环回网卡
  • WinCC 连接 IP 填的是 192.168.0.10，机架 0 插槽 1
适用环境：CPU 1214C，博图 V16 + S7-PLCSIM V16，WinCC V7.5，NetToPLCsim 最新版。如果 NetToPLCsim 始终无法连上 PLCSIM V16，可以复制一份项目把 CPU 更换为 S7-1500，改用 S7-PLCSIM Advanced V3.0 仿真。菜单位置以实际软件为准。
