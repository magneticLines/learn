📖 骨架书

《漫步华尔街》(马尔基尔) + 《共同基金常识》(博格) + 《经济学原理》(曼昆)

投资理财理念 — 以《漫步华尔街》为主线，辅以《聪明的投资者》：理财顺序、风险与收益、行为偏误、复利、分散化、资产配置。 先有理念再碰产品，避免一上来就追热点。

基金详解 — 以博格《共同基金常识》讲清楚基金的本质与成本，结合国内公募市场（货基、债基、指数基金、ETF、QDII 等）逐一拆开。

经济学基础 — 以曼昆《经济学原理》为主线，作为背景知识按需补：优先学通胀与货币政策，用来看懂"降息为什么股债会涨"。

🧭 学习顺序
  1. 先别亏大钱 — 理财顺序、风险收益对等、行为偏误
  2. 建立核心理念 — 复利、通胀、分散化、资产配置、债券利率（穿插经济学 Tab 的通胀 / 货币政策）
  3. 落到工具 — 货基放活钱、债基放稳健钱、指数基金放长期钱，盯紧费用
  4. 按需补充 — 其余资产类别、进阶基金品种、经济学其他章节

标 先学 的节点按 Tab 顺序学完，就覆盖了前三步。一句话：先学会不亏大钱，再学低成本拿到市场平均收益，最后才是想办法多赚一点。

来源:《漫步华尔街》 · 《聪明的投资者》 · 个人理财通识

  • 第一阶段 · 先别亏大钱
    • 理财顺序：应急金 → 保险 → 投资先学
    • 风险与收益对等：不存在高收益低风险先学
    • 行为金融：追涨杀跌、损失厌恶、过度自信先学
    • "四笔钱"：活钱 / 稳健钱 / 长期钱 / 保障钱
    • 个人资产负债表与现金流
  • 第二阶段 · 建立核心理念
    • 复利与货币的时间价值先学
    • 通胀如何侵蚀购买力：为什么钱不能只存着先学
    • 分散化：为什么不要把鸡蛋放一个篮子先学
    • 资产配置与再平衡先学
    • 有效市场假说与随机漫步进阶
  • 认识资产类别
    • 存款、国债与无风险利率
    • 债券：利率与价格为什么反向变动先学
    • 股票：所有权、分红与估值（PE / PB / ROE）核心
    • 黄金与大宗商品
    • 房产：消费品还是投资品

来源:《共同基金常识》 · 国内公募基金实务

  • 基金是什么
    • 基金的本质：集合投资、托管与信托关系核心
    • 净值、份额与申购赎回核心
    • 公募基金 vs 私募基金
    • 开放式 vs 封闭式基金
  • 第三阶段 · 按用途选工具
    • 货币基金：活钱放哪里（余额宝背后是什么）先学
    • 债券基金：纯债 / 一级债 / 二级债 / 可转债先学
    • 指数基金：宽基、行业与 Smart Beta先学
    • ETF、LOF 与场内场外
    • 股票型与混合型基金
    • QDII：投资海外市场
    • FOF 与养老目标基金进阶
    • REITs：把不动产变成基金进阶
  • 选基与持有
    • 基金费用：管理费、托管费、申赎费与 A 类 / C 类先学
    • 主动基金 vs 被动基金：基金经理值不值这个钱先学
    • 定投原理与"微笑曲线"先学
    • 业绩评估：年化收益、最大回撤与夏普比率
    • 常见坑：追冠军基金、频繁换基、只看短期排名
    • 指数估值与买卖时机进阶

来源:《经济学原理》微观 + 宏观分册 · 背景知识，按需补
